## Como capturar
- **Expo Go (celular):** abra cada tela e use a gravacao/print de tela nativa.
- **Android:** botoes Volume- + Power; ou no Android Studio, icone de camera no emulador.
- **iOS:** Cmd+S no simulador, ou print nativo no aparelho.

> Dica: para o print de Alertas, deixe a telemetria rodando alguns segundos
> ou ajuste um limiar bem proximo do valor atual na tela de Configuracoes para
> forcar o disparo de um alerta visivel.
