--------------------------------------------------------------------
PASSO 0 - PRE-REQUISITOS (instalar uma vez)
--------------------------------------------------------------------
- Node.js v20+ instalado (verifique: node -v)
- App "Expo Go" instalado no celular (Android ou iOS), OU um emulador
- Conexao do PC e do celular na MESMA rede Wi-Fi (para o QR Code funcionar)

--------------------------------------------------------------------
PASSO 1 - INSTALAR AS DEPENDENCIAS
--------------------------------------------------------------------
Abra o terminal NA PASTA do projeto (a pasta que contem o package.json):

    cd AETHER_Mobile_CrossPlatform
    npm install

Aguarde baixar tudo (cria a pasta node_modules, que NAO vai para o GitHub).

--------------------------------------------------------------------
PASSO 2 - RODAR E TESTAR (faca isso com atencao)
--------------------------------------------------------------------
    npx expo start

- Vai abrir um QR Code no terminal/navegador.
- Celular: abra o Expo Go e escaneie o QR Code (Android escaneia direto;
  iOS use a camera nativa e toque no link).
- Emulador: pressione "a" (Android) ou "i" (iOS) no terminal do Expo.

TESTE ESTES ITENS (todos devem funcionar SEM erro):
  [ ] App abre na tela "Visao Geral" e os valores mudam sozinhos a cada 2s
  [ ] Navegar entre as abas: Visao Geral, Sensores, Energia, Comunicacao,
      Alertas, Config
  [ ] Tela Alertas mostra "Ativos agora" e/ou historico
  [ ] Em Config, digite um limiar invalido -> aparece erro vermelho inline
  [ ] Corrija e clique "Salvar limiares" -> aparece "Limiares salvos"
  [ ] Toque no icone de sol/lua (canto superior) -> alterna tema claro/escuro
  [ ] Feche e reabra o app -> o tema e os limiares continuam salvos

Se algo der erro: rode "npx expo install" para alinhar versoes e tente de novo.
